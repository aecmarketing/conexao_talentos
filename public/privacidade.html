CONEXÃO TALENTOS · Recrutamento & Seleção

Política de Privacidade

O Conexão Talentos é um sistema de uso interno para gestão de recrutamento e seleção. Esta página explica como os dados são tratados.

Quais dados são tratados

Dados de vagas, processos seletivos e candidatos cadastrados pela equipe de recrutamento (como nome, e-mail, telefone, etapas do processo e observações), além das respostas ao questionário comportamental DISC enviadas pelos participantes.

Para que são usados

Exclusivamente para conduzir os processos seletivos da organização. Os dados não são vendidos, compartilhados com terceiros para fins comerciais nem usados para publicidade.

Onde ficam armazenados

Os dados ficam em uma pasta privada no Google Drive da própria organização. O acesso do sistema ao Google Drive é usado somente para ler e gravar os arquivos dessa pasta.

Uso das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Questionário DISC

O questionário tem caráter exploratório e não é um teste psicológico validado. O resultado não é usado isoladamente para decisões de contratação.

Seus direitos

Candidatos podem solicitar acesso, correção ou exclusão dos seus dados entrando em contato com a equipe de recrutamento responsável pelo processo seletivo.
